# Project instructions for the runner app

## Project context
This project is a Next.js app for runners. The product is intended for personal or non-commercial use and is not for commercial usage.

## Core product areas
Build the app around these sections:
- General pages: Home, About, Information, Help
- User pages: Overview
- Only the Overview page is required for now; other user pages may be added later

## Content and language
- Write all user-facing text in English.
- Keep content clear, simple, and friendly for runners.
- Use concise and practical copy rather than marketing-heavy language.

## Technical expectations
- Keep the app simple, maintainable, and easy to extend.
- Prefer a clean Next.js app-router structure.
- Build the initial pages in a way that supports future route expansion.
- Use TypeScript and modern React patterns when adding code.

## Safety and workflow rules
- Never commit or push anything without explicit confirmation.
- Never claim a change is complete without verifying it with a relevant command or check.
- Do not introduce commercial branding, sales language, or monetization logic.
- Maintain the project as a non-commercial runner app.

## Current implementation focus
Start with the initial app structure and the page set above, prioritizing:
1. Home
2. About
3. Information
4. Help
5. Overview

When implementing, keep the app functional and ready for later extension.
